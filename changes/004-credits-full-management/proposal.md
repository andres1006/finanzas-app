# Proposal: Full Credits Management & Traceability

## Goal
Upgrade the current Credits module from a simple list to a full management system. This includes the ability to register payments (abonos), view payment history (histórico), and see projections for debt-free dates.

## Scope
- **Payment Registration**: Form to add payments to specific credits.
- **Payment History**: Table or list showing all past payments for each debt.
- **Dynamic Projections**: Calculate how much time is left to pay off each debt based on the current minimum payment vs. extra payments.
- **Traceability**: Link each credit to its specific transactions in the Google Sheet.

## Context
Currently, users can only see the list of credits. There is no way to interact with them or see how they evolve over time.
